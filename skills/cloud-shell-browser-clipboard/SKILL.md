# Cloud Shell Chromium 공유 화면과 클립보드

Cloud Shell에서 에이전트가 사용자와 같은 Chromium을 보고 텍스트를 전달하도록 설정·진단·검증한다. 작업 요청 시 허용된 범위에서 직접 실행하고, 설명만 원할 때는 안내한다. 기존 브라우저, 클립보드, 프로필, 파일, 포트와 세션을 먼저 확인하고 보존한다. 검증용 구성은 기존 사용자 화면과 분리하고 필요한 경우 종료·재연결 영향을 알린다.

설치, 실행, 보안 설정 및 검증 명령은 [설정과 테스트](references/setup.md)를 따른다. `scripts/bridge.py`는 noVNC의 클립보드 보드에 버튼을 추가하고, `scripts/clipboard.js`는 선택한 텍스트를 그 브리지로 전달한다. 독립된 Cloud Shell 환경에서 이 브리지의 로컬 경로와 인증된 HTTPS 미리보기 경로를 통해 한글·영문 붙여넣기를 검증했다. 다른 세션에서의 동작은 다시 확인한다.

## 작동 조건

- Chromium을 X11 화면에 실행하고 x11vnc와 noVNC로 보여준다. Codex는 같은 Chromium의 로컬 CDP에 연결한다. 다른 브라우저·다른 프로필에 연결해 놓고 같은 화면이라고 주장하지 않는다.
- Chromium 프로필, 설정 및 재사용 스크립트는 Cloud Shell 홈에 둔다. 이미 실행 중인 프로필은 별도 프로세스와 공유하지 않는다. 기존 브라우저가 있으면 실제 실행 인자, 화면, CDP 및 noVNC 연결 관계를 파악하고 사용자의 선택을 보존한다.
- Cloud Shell VM 재시작 후 실행 중 프로세스와 홈 밖에 설치한 패키지가 사라질 수 있다. 홈의 기존 파일을 보존하면서 필요한 시스템 패키지를 재설치하고 구성 요소를 재실행한다. 영구 실행을 약속하지 않는다.
- 매 세션 `cloudshell get-web-preview-url -p 8080`으로 실제 미리보기 주소를 확인한다. 사용자 고유 주소를 문서에 박아 넣지 않는다. 미리보기 인증 여부와 재접속 시 변경 여부를 확인한다.
- x11vnc의 기본 선택 항목 동기화는 클립보드 브리지와 충돌할 수 있다. 기존 구동 옵션과 실제 동작을 확인하고 필요한 경우 별도 테스트 인스턴스에 `-nosel`을 사용한다. x11vnc 옵션을 바꾸려고 기존 세션을 강제 종료하지 않는다.

## 보안과 데이터 취급

클립보드 요청은 현재 세션의 실제 Cloud Shell HTTPS 미리보기 출처와 정확히 일치하는 경우에만 허용한다. 와일드카드, 접미사 비교 및 임의 Origin 반사는 허용하지 않는다. 콘텐츠·인증코드·비밀번호·클립보드 값을 서버 로그, URL, 공개 저장소 또는 진단 출력에 남기지 않는다. CDP·VNC·내부 서비스는 로컬에만 바인딩하고 공용 디버깅 포트를 열지 않는다. 브라우저·VNC는 사용자 데이터에 접근할 수 있으므로 Cloud Shell의 인증된 미리보기 뒤에서만 사용한다.

## 검증과 완료 조건

1. 현재 연결의 Chromium 버전, 고유 사용자 데이터 경로, CDP 엔드포인트 및 noVNC에 표시된 화면이 동일한지 확인한다. 새 탭을 만들었다면 테스트 탭만 정리한다.
2. 원격 입력란에 포커스를 맞추고 클립보드 보드에 `한글 English 123` 같은 비밀이 아닌 테스트 문구를 입력한 다음 **원격 화면에 붙여넣기** 버튼을 누른다. 입력란에서 문자열이 정확히 일치하는지 확인한다. 한글과 영문을 따로도 확인하고, 텍스트를 로그에 기록하지 않는다.
3. localhost 경로와 현재 `cloudshell get-web-preview-url -p 8080`으로 얻은 실제 HTTPS 미리보기 경로를 각각 테스트한다. 성공/실패와 어느 경로를 썼는지만 보고한다. 가짜 Origin, 빠진 Origin 및 다른 Origin은 거부해야 한다.
4. 사용자가 재접속을 요청하면 홈의 프로필·스크립트를 보존한 채 재실행하고 같은 브라우저 및 붙여넣기를 재확인한다. 기존 파일에 대한 덮어쓰기 전에 내용을 확인한다.

테스트가 어려운 환경에서는 빠진 실환경 검증을 명확히 보고하고, 로컬 모의 테스트나 설치 명령만으로 실제 미리보기·한글 전송 성공을 주장하지 않는다.
