# Cloud Shell Codex Skill

Google Cloud Shell에서 Linux, Codex CLI, tmux와 웹 미리보기 기반 브라우저를 사용하는 흐름을 안내합니다. Firefox·Chromium WebDriver의 실제 실행 검증 도구도 포함합니다.

스킬 본문: [skills/cloud-shell/SKILL.md](skills/cloud-shell/SKILL.md)

설치하려면 이 저장소를 클론한 뒤 `skills/cloud-shell` 폴더를 Codex의 사용자 스킬 디렉터리 `~/.codex/skills/cloud-shell`에 복사하고 새 대화를 시작하세요. 기존 폴더가 있으면 먼저 내용을 확인하세요.

Cloud Shell은 임시 실행 환경입니다. 홈 디렉터리의 보존, 세션 종료와 Google Cloud·OpenAI 사용 요금은 스킬에 연결된 공식 문서를 확인하세요.
